# 2027 연봉 실수령액 · 연말정산 환급금 계산기 (Paycheck & Tax Lab 2027)

서버나 데이터베이스 없이 **순수 HTML · CSS · Vanilla JS + LocalStorage**만으로 동작하는 Zero-Backend 웹서비스 2종 통합 프로젝트입니다.

- **라이브 웹앱**: https://ko9ma7.github.io/paycheck-tax-2027/
- **연봉 계산기 바로가기**: https://ko9ma7.github.io/paycheck-tax-2027/#salary
- **연말정산 계산기 바로가기**: https://ko9ma7.github.io/paycheck-tax-2027/#tax

## 주요 기능
1. **2027 연봉 실수령액 계산기**:
   - 2027년 4대보험 요율(국민연금 5.0%, 건강보험 3.595%, 장기요양 13.90%, 고용보험 1.0%) 반영 및 사용자 커스텀 지원
   - 연봉/월급 전환, 퇴직금 별도/포함, 비과세 식대, 부양가족·자녀세액공제 반영
   - 연봉 구간별(-500만 / 현재 / +500만 / +1,000만) 실수령액 비교표
2. **2027 연말정산 환급금 계산기**:
   - 연봉 계산기에서 입력한 총급여·4대보험·기납부세액을 원클릭 연동
   - 신용카드(15%) vs 체크카드·현금영수증(30%) vs 전통시장·대중교통(40%) 최저사용금액(25%) 황금비율 진단
   - 자녀 수별 카드 공제 한도 확대, 월세 세액공제(최대 1,200만 원), 연금저축·IRP(최대 900만 원) 반영
3. **내 정보 프로필 & 기록 관리 (Zero-Server Privacy)**:
   - 모든 입력값과 저장 프로필은 서버 전송 없이 **브라우저 `localStorage`**에만 저장
   - 여러 프로필(예: 현재 연봉, 이직 제안 비교) 저장/불러오기 및 **JSON 파일 백업/복원** 지원
